Deep Learning & Medical Imaging Nov 2024 – Dec 2024

PCOS Detection Using Ultrasound Images

Hybrid Diagnostic Framework via Deep Feature Extraction & Stacking

Architected an end-to-end medical AI diagnostic pipeline integrating fine-tuned deep learning backbones with ensemble learning to detect Polycystic Ovary Syndrome from ovarian ultrasound scans.

  • Extracted spatial representations using pre-trained VGG16 & ResNet50
  • Trained base ensemble models (Logistic Regression, SVM, Random Forest)
  • Refined predictions using an XGBoost meta-learner with weighted aggregation
